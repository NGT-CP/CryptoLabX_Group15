# Shift Cipher Cryptanalysis

## 1. Purpose

The purpose of this experiment is to perform cryptanalysis of a
Shift Cipher using three different approaches:

1. Brute Force
2. Dictionary Scoring
3. Chi-Square Analysis

The attacks are tested on multiple ciphertexts generated from known
plaintexts and keys. The predicted keys are compared with the actual
keys to evaluate the effectiveness of the cryptanalysis techniques.

---

## 2. Shift Cipher

A Shift Cipher is a substitution cipher in which every alphabetic
character is shifted by a fixed number of positions in the alphabet.

For example, with key 3:

Plaintext:

HELLO

Ciphertext:

KHOOR

During encryption, each letter is shifted forward by 3 positions.
During decryption, each letter is shifted backward by the same key.

The possible keys range from 0 to 25.

---

# 3. Cryptanalysis Algorithms

## 3.1 Brute Force Attack

### Algorithm

1. Take the ciphertext as input.
2. Try every possible key from 0 to 25.
3. Decrypt the ciphertext using each key.
4. Display the plaintext obtained for every key.
5. The correct plaintext can be identified by inspecting the
   generated results.

### Advantage

The method does not require any prior knowledge of the key.

### Limitation

There are only 26 possible keys for a Shift Cipher, but the correct
plaintext must be identified manually or using an additional scoring
method.

---

## 3.2 Dictionary Scoring Attack

### Algorithm

1. Take the ciphertext.
2. Try every key from 0 to 25.
3. Decrypt the ciphertext using the current key.
4. Split the decrypted text into words.
5. Check each word against the English dictionary.
6. Count the number of words found in the dictionary.
7. Repeat for all 26 keys.
8. Select the key with the highest dictionary score.
9. Return the corresponding plaintext.

### Advantage

The method uses meaningful English words to identify the likely
plaintext.

### Limitation

The result depends on the dictionary used. If a valid word is not
present in the dictionary, it will not contribute to the score.

---

## 3.3 Chi-Square Analysis

Chi-Square analysis uses the frequency distribution of letters in
English text.

A standard English frequency table is used as the expected
frequency distribution.

### Algorithm

1. Take the ciphertext.
2. Try every possible key from 0 to 25.
3. Decrypt the ciphertext using the current key.
4. Count the occurrences of each letter from A to Z.
5. Calculate the expected count of each letter using standard
   English letter frequencies.
6. Calculate the Chi-Square value for the decrypted text.

The formula used is:

χ² = Σ ((O - E)² / E)

where:

- O = observed frequency/count
- E = expected frequency/count

7. Repeat the process for all 26 keys.
8. Compare the Chi-Square scores.
9. Select the key with the lowest Chi-Square score.
10. Decrypt the ciphertext using the selected key.

A lower Chi-Square score means that the letter distribution of the
decrypted text is closer to the expected English distribution.

# 6. Failure Analysis

No attack failed in the five test cases used in this experiment.

However, the Dictionary Scoring approach can fail when the
plaintext contains words that are not present in the dictionary.
A limited dictionary can therefore reduce the accuracy of the
attack.

An improvement would be to use a larger English dictionary or a
frequency-ranked word list.

Chi-Square analysis can also become less reliable for very short
ciphertexts because a small number of letters may not represent the
normal English frequency distribution accurately.

An improvement would be to use longer ciphertexts or combine
Chi-Square analysis with another scoring technique.

---

# 7. Observations

1. Brute Force generates all possible plaintexts for the 26 possible
   Shift Cipher keys.

2. Dictionary Scoring selects the key whose decrypted plaintext
   contains the highest number of dictionary words.

3. Chi-Square Analysis selects the key whose letter-frequency
   distribution is closest to normal English.

4. In the five test cases, Dictionary Scoring correctly predicted
   the actual key in every case.

5. In the five test cases, Chi-Square Analysis also correctly
   predicted the actual key in every case.

6. Dictionary Scoring depends on the quality and size of the
   dictionary.

7. Chi-Square Analysis depends on the amount of ciphertext because
   frequency analysis becomes more reliable with longer text.

8. Both Dictionary Scoring and Chi-Square Analysis can reduce the
   amount of manual inspection required compared with basic
   Brute Force.

---

# 8. Conclusion

This experiment demonstrated three approaches for cryptanalysis of
a Shift Cipher: Brute Force, Dictionary Scoring, and Chi-Square
Analysis.

Brute Force tests all possible keys, while Dictionary Scoring uses
English words to identify the most likely plaintext. Chi-Square
Analysis uses statistical comparison between the letter frequencies
of decrypted text and standard English letter frequencies.

In the five test cases conducted, both Dictionary Scoring and
Chi-Square Analysis correctly predicted the actual key in all cases.

The experiment showed that statistical and language-based scoring
methods can automate the identification of the most likely key
instead of requiring manual inspection of every possible
decryption.
